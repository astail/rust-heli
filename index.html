Rust Heli Trainer

Rust の Minicopter 風の操縦をブラウザで練習するための非公式シミュレーター

モード

操作 (Rust のデフォルト準拠)

Wスロットル上昇 (上昇)
Sスロットル下降 (降下)
A / Dヨー (機首を左右に回す + 旋回方向へ傾く。傾きは自動で戻らないのでマウスで直す)
マウス 前後ピッチ (前傾で前進 / 後傾で減速・後退)
マウス 左右ロール (横に傾けて旋回・横移動)
C / V視点切替 (機内 / コックピット / 近接 / TPS / チェイス / 俯瞰)
Rリスポーン
Esc一時停止 / メニュー

設定

機内視点のカメラ位置 飛行中はマウスホイールで距離を調整できます

PC + マウス推奨。開始するとマウスがロックされます (Esc で解除)。
