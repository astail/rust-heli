# Rust Heli Trainer

ゲーム「Rust」の Minicopter 風ヘリコプター操作をブラウザで練習できる非公式シミュレーターです。

**▶ プレイ:** https://astail.github.io/rust-heri/

## 操作
| キー | 動作 |
|---|---|
| W / S | スロットル上昇 / 下降 |
| A / D | ヨー (左右旋回) |
| マウス前後 | ピッチ |
| マウス左右 | ロール |
| C | カメラ切替 |
| R | リスポーン |
| Esc | メニュー |

## モード
- フリーフライト
- リングコース (タイムアタック)
- 着陸チャレンジ (ヘリパッド・屋上)
- ホバリング (20秒静止)

Three.js 製の単一 HTML。ビルド不要。Facepunch Studios とは無関係のファンメイドです。
