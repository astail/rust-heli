# Rust Heli Trainer

ゲーム「Rust」の Minicopter 風ヘリコプター操作をブラウザで練習できる非公式シミュレーターです。

**▶ プレイ:** https://astail.github.io/rust-heli/

## 操作
| キー | 動作 |
|---|---|
| W / S | スロットル上昇 / 下降 |
| A / D | ヨー (左右旋回) |
| マウス前後 | ピッチ |
| マウス左右 | ロール |
| C / V | 視点切替 (パイロット / 機内 / コックピット / 近接 / TPS / チェイス / 俯瞰) |
| R | リスポーン |
| H | HUD 表示 ON/OFF |
| Esc | メニュー |

## モード
- フリーフライト
- リングコース (タイムアタック)
- 着陸チャレンジ (ヘリパッド・屋上)
- ホバリング (20秒静止)

ローター音 (風切り音なし) は Web Audio で合成 (デフォルトON・音量1/4、設定でOFF可)。

HUD (数値・姿勢計・WASD/マウス・ミッション表示) は設定の「HUD の位置・サイズを変更」で自由に配置できます。

Three.js 製の単一 HTML。ビルド不要。Facepunch Studios とは無関係のファンメイドです。
